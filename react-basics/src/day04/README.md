# Day 4 미니 과제 — 임대 매물 목록 서비스

> **제한 시간: 90분** (요구사항 분석 10분 포함)
> 시작 시각과 종료 시각을 기록하고, 시간이 되면 완성 여부와 관계없이 멈춘다.

## 과제 설명

임대 매물을 검색하고, 상세 정보를 확인하고, 관심 매물을 즐겨찾기할 수 있는 화면을 만든다.

## 제공되는 것

| 파일 | 내용 |
|---|---|
| `src/day03/api.ts` | 매물 API (`fetchProperties`, `fetchProperty`, `createProperty`, `deleteProperty`, `setFailMode`) |
| `src/day02/types.ts` | `Property`, `Category`, `CATEGORY_LABEL` |
| `main.tsx` | `QueryClientProvider` 설정 완료 |

API와 타입은 import해서 사용한다. **컴포넌트, 훅, 화면 코드는 새로 작성한다** (Day 2~3 코드 복사 금지).

## 요구사항

1. 매물 목록을 API에서 불러와 보여준다. 각 항목에는 매물명, 유형, 보증금/월세가 표시된다.
2. 매물명으로 검색할 수 있다.
3. 유형(전체 / 아파트 / 오피스텔 / 원룸)으로 필터링할 수 있다.
4. 매물을 선택하면 상세 정보(면적, 설명 포함)를 API에서 불러와 보여준다.
5. 매물을 즐겨찾기에 추가하거나 해제할 수 있다. 목록과 상세 화면 모두에서 즐겨찾기 상태가 보인다.
6. "즐겨찾기만 보기"로 목록을 거를 수 있다.
7. 목록과 상세 각각 loading / error / empty 상태를 처리한다. error 상태에서는 다시 시도할 수 있다.
8. 즐겨찾기는 새로고침해도 유지된다.
9. 목록을 월세 낮은 순 / 면적 넓은 순으로 정렬할 수 있다.
10. 매물을 삭제할 수 있다. 삭제 후 목록이 갱신된다.
11. 검색어, 필터, 정렬 조건을 한 번에 초기화할 수 있다.
